# Reproducible Open Science Workflow Evaluation

## Purpose
This repository contains the materials used to evaluate whether an integrated GitHub–Zenodo–ORCID workflow improves reproducibility, traceability and transparency compared with a conventional publication-centred workflow.

## Repository contents
- literature/: search strategy and literature extraction data
- data/: requirement matrix and workflow scoring data
- analysis/: scripts used to calculate reproducibility scores
- results/: generated results
- docs/: workflow and reproduction protocols
- manuscript/: manuscript and figures

## How to reproduce the analysis
1. Clone the repository.
2. Install dependencies.
3. Run the analysis script.
4. Compare generated outputs with the files in results/.
